Liteview 便携浏览器

启动
  将压缩包解压到有写入权限的普通文件夹，双击 Liteview.exe 运行。
  Liteview 本身无需安装或管理员权限，不建议放进 Program Files 等受保护目录。
  电脑需要安装 Microsoft Edge WebView2 Evergreen Runtime。
  如果提示缺少运行时，请从微软官方渠道安装；项目中的 SDK 不能代替运行时。

基本使用
  在地址栏输入网址或关键词，按 Enter，或点击地址栏右端的箭头。
  普通网址不带协议时默认使用 HTTPS；localhost 等本机回环地址默认使用 HTTP。
  关键词使用必应（Bing）搜索；需要明确协议时，请输入完整网址。
  也可以输入本地 HTML 文件的完整路径或 file:// 地址。
  地址栏左侧依次为后退、前进、刷新/停止和主页按钮，支持鼠标侧键前进、后退。
  地址栏右侧的三点菜单提供新建标签页、新建窗口、缩放、全屏、历史记录和退出功能。

标签页与窗口
  点击顶部 + 新建标签页，点击标签切换；灰色背景表示当前标签。
  点击标签上的 ×，或用鼠标中键点击标签，可以关闭它。
  各标签独立保留页面和前进、后退记录；网页请求的新窗口在新标签中打开。
  标签较多时，可使用标签栏的滚动箭头查看。
  拖动顶部空白区域可以移动窗口，双击该区域可以最大化或还原。
  新建窗口后，同一次运行创建的窗口共享 Data，但各自的标签独立。
  关闭最后一个标签会关闭所在窗口，其他窗口继续运行。
  右上角 × 只关闭当前窗口；菜单底部“关闭 Liteview”关闭本次运行创建的全部窗口。
  退出后不恢复上次打开的标签页。

常用快捷键
  Ctrl+L / Ctrl+K              选中地址栏内容
  Alt+左 / Alt+右             后退 / 前进
  F5 / Ctrl+R                 刷新；加载中按下则停止
  Esc                         停止加载；全屏时退出全屏；菜单展开时收起菜单
  Alt+Home                    打开内置主页
  Ctrl+T                      新建标签页
  Ctrl+W / Ctrl+F4            关闭当前标签页
  Ctrl+Tab / Ctrl+Shift+Tab    下一个 / 上一个标签页
  Ctrl+1～8 / Ctrl+9          对应位置的标签页 / 最后一个标签页
  Ctrl+N                      新建窗口
  Ctrl++ / Ctrl+-             放大 / 缩小网页，范围为 25%～500%，按标签保留
  Ctrl+0                      恢复 100% 缩放，也可点击菜单中的缩放百分比
  F11                         进入 / 退出全屏
  Ctrl+H                      打开历史记录
  Alt+F / F10                 展开三点菜单；点击菜单外部也可收起

历史记录
  成功打开的 HTTP、HTTPS 页面和本地文件记录在 Data\history.tsv 中。
  不记录内置主页和历史页，历史页可按标题或网址筛选，点击记录重新访问。
  历史页最多显示最近 500 条，受页面大小上限限制；筛选作用于当前显示的记录。
  历史文件过大时会自动缩减，只保留较近的部分记录，不作为永久访问档案。

数据与迁移
  网页缓存、Cookie、网站存储和历史记录等保存在 EXE 旁的 Data 文件夹。
  备份或搬移：关闭全部 Liteview 窗口后，复制整个程序文件夹。
  升级：关闭全部窗口后替换程序文件，保留 Data。
  重置：关闭全部窗口后删除 Data，下次启动会重新创建。
        原有登录状态、历史记录和网站数据会丢失。
  登录凭据可能受系统加密保护，跨电脑搬移不保证保留登录状态。
  程序本体小不代表内存和浏览数据占用也小，缓存会随使用增长。
  程序不创建安装项、卸载项、自身的注册表配置或系统快捷方式。
  系统和 WebView2 仍可能留下正常运行记录；便携版不等于无痕浏览。
